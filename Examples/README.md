# UIKit example

Open `UIKitDemo/TMProgressHudDemo.xcodeproj`, select `TMProgressHudDemo` and run on iOS 15+ or tvOS 15+. The project uses the local Swift package.

Try all six modes and the Close action. On tvOS, the view controller directs focus to the HUD action button and restores the menu after dismissal. The Objective-C test reference is not linked into the example.
